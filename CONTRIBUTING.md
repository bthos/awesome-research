## How to Contribute

1. Fork the repository
2. Create your feature branch from `main`
3. Add your research document or improvements
4. Update the README.md to include your new research in the appropriate category
5. Submit a pull request

## Adding Research Documents

### File Naming Convention

Research documents should follow the naming pattern:
```
YYYYMMDD-topic-name-research.md
```

Example: `20251130-browser-ai-api-research.md`

### Document Structure

Each research document should include:

1. **Title** - Clear, descriptive title using heading level 1
2. **Research Executed** - Section describing the research methodology
3. **Key Discoveries** - Main findings and insights
4. **Code Examples** - Where applicable, include code snippets
5. **Recommended Approach** - Practical implementation guidance (if applicable)

### Categories

Research documents should fit into one of these categories:
- Azure DevOps Integration
- Browser AI & Machine Learning
- Editor & Widget Implementation

If your research doesn't fit existing categories, propose a new category in your pull request.

## Quality Standards

- **Accuracy**: Ensure all information is accurate and verified
- **Clarity**: Write clearly and concisely
- **Code Examples**: Include working code examples where applicable
- **Attribution**: Credit sources and provide references
- **Formatting**: Use proper Markdown formatting
- **Completeness**: Include enough detail for others to understand and apply the research

## Pull Request Guidelines

- [ ] Research document follows the naming convention
- [ ] Document includes all required sections
- [ ] README.md is updated with a link to the new research
- [ ] Research is placed in the appropriate category
- [ ] Markdown is properly formatted (no linting errors)
- [ ] Code examples are tested and working (if applicable)
- [ ] Links and references are valid

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing. We are committed to providing a welcoming and inclusive environment for all contributors.
